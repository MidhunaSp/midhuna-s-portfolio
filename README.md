<br>

Ever wished a portfolio felt less like a resume and more like poking around someone's laptop? That's this.

Open folders. Drag windows around. Click through Projects, Resume, and Contact like they're real apps — because on this desktop, they kind of are.

<br>

## what's inside

- 🖥️ **a whole desktop** — menu bar, dock, draggable windows, the works
- 🌷 **hand-drawn wallpaper** — a little anime garden, cherry blossoms and all
- 📁 **real folders** — About Me, Projects, Resume, Contact
- 📸 **a photo viewer** — click into achievements & events to see them
- ✨ **zero dependencies** — pure HTML, CSS, JavaScript. nothing to install, nothing to break

<br>

## built with

`HTML` · `CSS` · `JavaScript`

<br>

## running it

```bash
git clone https://github.com/MidhunaSp/midhuna-s-portfolio.git
```

then just open `index.html`. that's it. that's the setup.
